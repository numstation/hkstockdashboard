# 版本歷史記錄

## Version 2.0.1 (當前版本) - 智能行使價計算優化

### 🎯 改進功能

#### 動態行使價計算策略
- ✅ **橫盤市場 (ADX < 25)**: 保守策略
  - 賣出認沽：`min(布林下軌, 收盤價 - 2*ATR)`
  - 賣出認購：`max(布林上軌, 收盤價 + 2*ATR)`
  - 理由：橫盤市場需要更多安全邊際

- ✅ **強勢趨勢市場 (ADX > 30)**: 積極策略
  - 上升趨勢賣出認沽：`收盤價 - 1.5*ATR`（忽略布林下軌）
  - 下降趨勢賣出認購：`收盤價 + 1.5*ATR`（忽略布林上軌）
  - 理由：趨勢明確，可以更接近當前價格以獲取更好溢價

### 技術改進
- 根據市場狀態動態調整行使價計算邏輯
- 趨勢市場使用更積極的 1.5x ATR 倍數
- 橫盤市場保持保守的 2x ATR 倍數並考慮布林通道

## 如何更新版本

當您有新的更新想法時：

1. **更新版本號碼**:
   ```bash
   # 編輯 version.txt，例如從 1.0.0 改為 1.1.0
   echo "1.1.0" > version.txt
   ```

2. **更新 app.py 中的版本號碼**:
   ```python
   VERSION = "1.1.0"
   ```

3. **記錄更新內容**:
   - 在此檔案中添加新版本的更新記錄
   - 描述新增功能、修復的問題等

4. **備份當前版本**（可選）:
   ```bash
   # 創建版本備份目錄
   mkdir -p versions/v1.0.0
   cp -r *.py *.html *.txt versions/v1.0.0/
   ```

### 版本號碼規則

使用語義化版本號：`主版本號.次版本號.修訂號`

- **主版本號**: 重大變更，不相容的 API 變更
- **次版本號**: 新增功能，向後相容
- **修訂號**: 錯誤修復，小幅度改進

範例：
- 1.0.0 → 1.0.1 (修復小錯誤)
- 1.0.1 → 1.1.0 (新增功能)
- 1.1.0 → 2.0.0 (重大變更)
